你将**一次性**看到本 PPT **全部页面截图**（按页码顺序附于本提示之后）以及**用户整场演讲全文**。请对照每一页画面，在全文里**只做切段分配**（必要时按规则做**格式清理**）：为每一页判定应读出的**连续原文**区间。

你不重新撰稿：**不得**同义改写、概括扩写、润色、增补或删减原意；**不得**为适应画面而替换用词。允许的唯一整理：**格式归一化**（见「格式清理」：清除 HTML 粘贴污染、合并重复加粗、纠正错误反斜杠转义）；**不得**擅自拆掉用户稿中的 Markdown 结构（标题、列表层级等）。

## 硬约束（按优先级）

### 1. 全文覆盖与顺序（最高）
- 将全部页口播**按页码顺序拼接**后，须**完整覆盖**用户整场演讲全文中的实质性正文，**不得**遗漏任何 `##` / `###` 整节或列表段落。
- **禁止跳节**：尚未分配的任何实质性原文都须按顺序进入某页口播；画面匹配不能作为跳段理由。
- **禁止重复**：同一句、同一段不得在多个页面重复出现（封面/目录式页对极短标题词的适度复现除外）。
- 各页口播在全文中的区间须**首尾相接、互不重叠**（允许页与页之间仅差空白/换行）。
- 分页经验：通常第一页是标题，第二页是导入说明；若某段内容被拆成连续多页，其中某一页可能只对应一句短过渡。

### 2. 全局分镜对齐
- 先通读全部截图，理解 NotebookLM 等工具可能把**同一章节拆成多页**、或把**导入/破题与第一个编号章**分到不同页。
- **封面/片头**：主标题页通常只取标题行（极短同行衬题可一并取），不要把长段导入并进封面。
- **导入/总览页**：无编号铺垫、短引子、章级过渡通常留在导入页；紧随其后的第一个 `##` 编号章或 `###` 子节，若版式更匹配后页，**不得**提前并入导入页。
- **正文分节**：自编号小节起，结合当页与后页版式对齐止点；同一节可跨多页，但须连续续读，**不得**因后页更像而跳过前节。

### 3. 格式清理（TTS 友好 · 硬约束）

用户稿常从 HTML 富文本编辑器复制粘贴到 Markdown 编辑器，可能混入 `<br>`、`<strong>` 与 `**`。输出将直接用于 TTS：残留 HTML 或字面量 `**` 会被朗读出来。清除标记噪音**不属于改写**，不得改字、改序、改义，但**必须**做下列归一化。

#### 3.1 输出标准
- 每页 `speech` 为稿中**连续原文截取**后的**最小清理**；仅输出**纯 Markdown**：允许 `##` / `###`、列表 `-` / `*` / `1.`、成对 `**加粗**`、成对 `*斜体*`、普通换行。
- **禁止**任意 HTML 标签与 HTML 实体（如 `&nbsp;`、`&amp;`）；输出中不得出现 `<` 后接字母构成的标签。

#### 3.2 HTML 清除
- `<br>`、`<br/>`、`<br />`、`<BR>` 等 → 单个换行；连续多个最多保留一个空行。
- `<p>…</p>`、`<div>…</div>` 等块级标签 → 删标签保留内文，段末换行。
- 删除其余 HTML 标签（含 `<span>`、`<font>` 等），保留标签内文字。
- HTML 实体：`&nbsp;` → 空格；`&amp;` → `&`；`&lt;` / `&gt;` → 解码后若成标签则按上条处理。

#### 3.3 加粗 / 斜体去重
- 每个强调片段**只保留一种表示**：加粗只能是 `**文字**`，斜体只能是 `*文字*` 或 `_文字_`（任选一种，全文一致）。
- 若已有 `**文字**`，删除内侧 `<strong>` / `<b>` / `<em>` 等，保留 `**文字**`。
- 若仅有 `<strong>文字</strong>`（或 `<b>`）而无 `**`，转为 `**文字**`。
- **禁止**叠层：`****文字****`、`**<strong>文字</strong>**`、`<strong>**文字**</strong>` 等；合并为单一 `**文字**`。
- 勿新增原稿没有的强调；勿删除原稿已有的强调语义。

#### 3.4 转义与其它
- **禁止**输出 `\*\*`、`\#` 等错误转义；仅去掉多余 `\` 恢复 Markdown。
- 单独一行的 `***` / `---` 可删或改为空行；勿删正文行内强调。
- 换行贴近原稿，避免连续三个以上空行。

#### 3.5 输出前自检
每项 `speech` 写入 JSON 前须自检，不通过则修正后再输出：
- 不含 `<` 开头的 HTML 标签；
- 不含 `&nbsp;`、`&strong;` 等 HTML 实体；
- 加粗仅为成对 `**…**`，无与 HTML 混用、无 `****` 叠层；
- `**` 仅作强调定界，不作为需朗读的正文残留。

#### 3.6 示例
- `第一行<br />第二行` → `第一行` + 换行 + `第二行`
- `**<strong>招聘雷区</strong>**` → `**招聘雷区**`
- `<strong>多元雇佣</strong>与反歧视` → `**多元雇佣**与反歧视`
- `<p>段落一</p><p>段落二</p>` → `段落一` + 空行 + `段落二`

## 返回格式（必须严格遵守）

- 只返回 JSON，不要解释文字，不要代码块围栏。
- 顶层结构：

```json
{
  "pages": [
    {
      "page_number": 1,
      "speech": "..."
    }
  ]
}
```

- `pages.length` 必须等于 PPT 页数。
- `page_number` 必须从 `1` 开始严格连续递增到 `N`。
- `speech` 必须为字符串，不得为空，不得包含 HTML 标签或 HTML 实体。
